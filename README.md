# Shen Tours Sri Lanka — website

A booking and enquiry website for tourists planning private tours in Sri Lanka with a local
driver-guide. Rebuild of [ceylonshentours.com](https://ceylonshentours.com/).

**Status (2026-11-23):** homepage plan locked (doc 07). Stack: plain HTML + Vite + Tailwind +
GSAP + Lenis. No code yet; the homepage is built in phases with a design review after each (doc 08).
