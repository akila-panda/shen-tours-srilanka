# 02 — SEO strategy

## Keyword research

Source: OpenSEO (DataForSEO), pulled 2026-11-18. Monthly Google searches. Market is the **UK**
unless marked (US = United States, AU = Australia). KD = keyword difficulty 0–100 (lower is
easier). Treat volumes as directional; re-pull once the target markets are confirmed (doc 00).

### Finding 1 — tourists don't search "day tours"; they search places and experiences

`sri lanka day tours` gets **10**/month. `sigiriya` gets **14,800**. The traffic is in destination
and attraction names, so **destination and experience pages are the main SEO lever**, with tours
listed on them.

### Finding 2 — almost everything is low difficulty

Most Sri Lanka terms sit at KD 0–15. A well-structured, fast site with real content can rank. The
big informational terms (weather, visa, best time) are the only crowded ones.

## Keyword-to-page rules

- **One primary keyword per URL.** No two pages target the same primary term.
- Title pattern: `{Primary keyword, natural phrasing} | Shen Tours Sri Lanka` — ≤ 60 chars.
  Tour pages: `{Tour name} – {duration}, from {price} | Shen Tours`.
- One `<h1>` per page containing the primary keyword. Meta description ≤ 155 chars, written as a
  pitch with a fact (duration, price, pickup) — never stuffed.
- Every destination page links to the tours that visit it; every tour page links back to its
  destinations and experiences. That two-way mesh is the internal-linking backbone.

## URL structure

Lowercase, hyphenated, no file extensions, no dates, no IDs. Trailing slash: none (pick once,
redirect the other).

```
/                                   Home
/tours                              All tours (filterable)
/tours/day-tours                    Category
/tours/round-tours                  Category
/tours/{tour-slug}                  Tour detail (flat — category is data, not path)
/destinations                       Destinations hub (map)
/destinations/{place}               Destination
/experiences/{theme}                Safaris, whale watching, honeymoon, cultural triangle…
/day-tours-from/{town}              Pickup-town landing pages (only towns we really pick up from)
/tailor-made                        Plan-your-trip
/private-driver-tours               Chauffeur/driver-guide service
/airport-transfers                  Transfers
/guides                             Travel guide hub
/guides/{slug}                      Guide article
/reviews  /about  /contact  /faq
/book/{tour-slug}                   Reservation request (noindex)
/privacy  /terms  /booking-terms
```

Tour slugs are flat (`/tours/yala-safari-from-bentota`) so a tour can belong to several
categories without duplicate URLs.

## Structured data (JSON-LD)

| Page | Schema |
|------|--------|
| Every page | `Organization` + `TravelAgency` (once SLTDA no., address, phone are confirmed), `WebSite`, `BreadcrumbList` |
| Tour detail | `TouristTrip` (itinerary as `ItemList` of `TouristAttraction`), `Product` + `Offer` (price, currency, availability) + `AggregateRating` **only from real reviews**, `FAQPage` |
| Tour listing / category | `ItemList` |
| Destination | `TouristDestination` / `TouristAttraction`, `ItemList` of tours, `FAQPage` |
| Guide | `Article` (author, datePublished, dateModified), `FAQPage` where it has Q&As |
| Reviews | `Review` items pointing at real platform reviews |
| FAQ | `FAQPage` |

## Technical SEO checklist

- Static HTML for every indexable page (no client-only rendering of content). See doc 04.
- `sitemap.xml` (auto-generated) + `robots.txt`; `/book/*` and thank-you pages `noindex`.
- Canonical on every page; filter/query-string versions of `/tours` canonicalise to the clean URL.
- Core Web Vitals targets: LCP < 2.0s on 4G, CLS < 0.05, INP < 200ms. Animations must not block
  LCP (hero text visible in the first paint, animated in, not hidden until JS).
- Images: AVIF/WebP, responsive `srcset`, width/height set, descriptive `alt` (place + subject),
  lazy below the fold, hero image `fetchpriority="high"`.
- Open Graph + Twitter cards per page with a real photo.
- `hreflang` only when a second language ships (not v1).
- 404 page with search + popular tours. 301 map for any legacy URLs.
- Google Search Console + Bing Webmaster verified at launch; submit sitemap.

## Off-page / local (outside the codebase, owner actions)

- **Google Business Profile** for the base town — category "Tour operator". Biggest local win.
- TripAdvisor listing claimed and linked; ask every guest for a review.
- Consistent NAP (name, address, phone) everywhere.
- Listings: SLTDA directory, Viator/GetYourGuide (also a booking channel), Lonely Planet forum
  presence, travel-blogger guest posts.
